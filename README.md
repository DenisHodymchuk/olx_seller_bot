# 🤖 OLX MakerWorld Telegram Bot

Автоматичний бот для публікації 3D-іграшок, декору та виробів з пластику на **OLX.ua** напряму за посиланням із **MakerWorld** (`makerworld.com`).

## Як це працює
1. Ви надсилаєте боту посилання на модель з MakerWorld (наприклад: `https://makerworld.com/en/models/123456`).
2. Бот автоматично (з обходом захисту через імітацію браузера `curl_cffi`) витягує всі фотографії високої якості, оригінальну назву, опис і теги.
3. **Google Gemini AI** перекладає та адаптує технічний англомовний опис під готовий фізичний товар українською мовою для покупця на OLX (прибирає зайві технічні деталі про слайсер, додає інформацію про еко-пластик PLA/PETG, вибір кольору та OLX Доставку) і підбирає категорію.
4. Бот показує альбом фото та прев'ю оголошення в Telegram і просить **ввести ціну в грн**.
5. Ви вводите число (наприклад, `350`) та натискаєте **«🚀 ОПУБЛІКУВАТИ В OLX»** — бот створює оголошення у вашому бізнес-магазині OLX (м. Хмельницький, Денис, `0689531334`).

---

## Швидкий запуск

### 1. Встановлення залежностей
```powershell
pip install -r requirements.txt
```

### 2. Налаштування ключів у файлі `.env`
Відкрийте файл `.env` і вставте 3 ключі:
- `BOT_TOKEN` — токен вашого Telegram-бота від `@BotFather`
- `OLX_CLIENT_SECRET` — секретний ключ із кабінету розробника OLX (натисніть `»»` біля `Client Secret` у вашому запиті `bubatg`)
- `GEMINI_API_KEY` — безкоштовний ключ Google Gemini API (з [Google AI Studio](https://aistudio.google.com/app/apikey))

*(Місто `Хмельницький`, ім'я `Денис`, телефон `0689531334`, `Client ID: 202769` та `Redirect URI: https://bubatgshop-production.up.railway.app/` вже прописані!)*

### 3. Запуск бота
```powershell
python bot.py
```

### 4. Підключення OLX акаунту (один раз)
1. Напишіть боту в Telegram команду `/auth`.
2. Натисніть кнопку **«🔑 Авторизувати бота в OLX»** та підтвердіть доступ.
3. Якщо бот розгорнутий на вашому домені Railway (`https://bubatgshop-production.up.railway.app/`), він автоматично прийме токен через вбудований веб-сервер. Якщо запускаєте локально на ПК — просто скопіюйте посилання, на яке вас перенаправило після підтвердження (де є `?code=...`), і відправте його боту в чат! Далі бот сам зберігатиме й автоматично оновлюватиме токен.
